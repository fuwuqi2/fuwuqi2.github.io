下单流程

从进专区到完成购买，一共 5 步。本导航只负责把你带到官方活动页，之后的下单、支付、开通都在云厂商官方完成。下面每一步讲清楚点哪里、注意什么。

进入对应厂商专区

从 总站首页 进入你想买的厂商专区（腾讯云 / 阿里云 / 京东云 / 雨云）。每个专区都是独立站点，收录该厂商全部官方入口。

选择优惠入口

在专区里选择你要的活动入口，比如「新客」「国内站」「国际站」「建站」等。点「前往」会跳转到云厂商官方活动页，请确认跳转后的域名是官方域名（如 aliyun.com、qcloud.com、3.cn、rainyun.com）。

在官方页面选规格

在官方活动页选择地域、规格、镜像、带宽、购买时长等。建议：
· 地域按用户就近或备案需求选。
· 规格从够用的最小规格起步。
· 新账号优先看新客价活动。
· 时长按验证周期选，别一上来就多年。

确认订单并支付

核对订单明细（规格、时长、价格、活动优惠），确认无误后支付。支付完成后服务器会在几分钟内开通，你会获得公网 IP 和登录凭据。

登录并开始使用

用获得的凭据登录服务器，按用途部署应用。如果是国内节点且绑定域名，记得先启动 ICP 备案流程，否则域名无法访问。

注意事项

下单前务必确认这几件事

🔐

确认是官方域名

跳转后确认域名是官方域名，避免落到仿冒或加价页。本导航只收录官方入口，但请以跳转后实际域名为准。

📋

看清活动规则

新客价、套餐、优惠叠加等规则以官方活动页说明为准，下单前先看清楚，避免买错。

📦

别一次买太多

先买够用的最小规格和短时长验证，确认稳定再升配续费，避免用不满造成浪费。

🌐

备案提前规划

国内节点绑定域名需备案，周期 7–20 工作日，建议项目启动阶段就同步启动。
